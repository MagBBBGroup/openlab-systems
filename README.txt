OPENLAB SYSTEMS MULTI-PAGE WEBSITE

Upload all HTML files, style.css and site.js to the ROOT of your GitHub Pages repository. Keep your existing logo.png in the same directory.

GitHub Pages: Settings > Pages > Deploy from a branch > main / (root).

Edit the placeholder YOUR-EMAIL@example.com in contact.html before publishing.

Product pages use photograph placeholders until actual system photos are available.

All navigation uses relative links, so the site works at https://magbbbgroup.github.io/openlab-systems/ and locally.

No frameworks or build steps are required. The optional Google Fonts stylesheet uses the internet; system font fallback works offline.


NEW: Six original SVG concept illustrations are in illustrations/. Each product page uses its matching drawing. They are editable vector files and deliberately schematic, not verified engineering plans.
