How it would work

Researchers choose a supported analysis environment and compatible GPU option. The Docker environment launches with the required software and dependencies already installed. They upload or mount their recordings, use the analysis tools and download their results. Our aim is to make the process as close as possible to upload, analyse and export — without requiring researchers to configure Docker, Python or CUDA themselves.

This service is under development. Docker environments require compatible GPU drivers and infrastructure on the host; we plan to test supported combinations. GPU hosting and storage would be provided by third-party services, with pricing and billing arrangements confirmed before launch.
