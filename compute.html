How it would work

Researchers select a compatible third-party cloud provider, rent appropriate computing resources, launch a supported environment, and upload or mount recordings for analysis. Results can then be exported for further use.

This is a planned service. GPU hardware, storage and computing charges would be supplied and billed by independent cloud providers, not OpenLab Systems.
