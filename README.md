# Open Research Instrumentation website

Static one-page site for GitHub Pages.

## Publish
1. Create a GitHub repository.
2. Upload `index.html` and `style.css` to the repository root.
3. Replace `YOUR-EMAIL@example.com` and `YOUR-GITHUB` in `index.html`.
4. Go to **Settings → Pages** and publish from your main branch/root.
5. GitHub will give you a `github.io` URL.

No framework or build process is required.
